# Eco Phrases

Aplicação para armazenamento e revisão de frases.

## Estrutura

- `eco-phrase-front` — frontend da aplicação
- `eco-phrases-back` — API REST em Java/Spring Boot

## Tecnologias

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Spring Security
- JWT
- PostgreSQL

### Frontend
- HTML
- CSS
- JavaScript
